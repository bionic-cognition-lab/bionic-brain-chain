# Bionic Brain Chain

**Project site:** https://bionic-cognition-lab.github.io/bionic-brain-chain/

Five LLM agents, each modeled on a brain region (Prefrontal Cortex, Amygdala, Hippocampus, Default Mode Network, and a Knowledge Verifier), answer questions about the brain and learning by passing work along a fixed pipeline. Built on the Knowledge Building Garden platform for the course *Brain and Learning*, with *Brain Facts* (Society for Neuroscience) as the core textbook.

This repository holds the public project site: the role of each station and the scores of every recorded trial run. The rules, textbook pages, platform findings, and experiment log are kept private until the inter-group contest is over, and will be published afterwards.
